HLEDAN / IN MEMORY OF MADRIC A

SOME PLACES
stay with us.

The Hledan map was the last gift my friend Madric A gave me before he passed away from cancer.

He built this little piece of Yangon. I brought it to the browser — with changing skies, weather, and a way to walk through it. His name stays with this project.

Original 3D map modeling — Madric A
Web rendering, lighting, weather & interaction — Thomas D. Lynn

ABOUT / THOMAS D. LYNN

THE PERSON BEHIND THE PROJECTS
Thiha Lynn

THIHA LYNN · BACKBENCHERS STUDIO

The One Piece influence ＋

One Piece has been a visual thread through this portfolio: the ship, the Jolly Roger, and a habit of exploring new ideas.

A builder acrossdisciplines.

I’m Thomas, also known as Thiha Lynn. An independent software engineer working through Backbenchers Studio, with projects rooted in Myanmar and built for different communities.

I move between games, web platforms, mobile apps, and the less glamorous systems that make them work: admin tools, integrations, publishing pipelines, and order workflows.

Some of this work is for businesses. Some is for a community. Some is for a childhood friend, a poet, a teacher, or a band. The common thread is making something that feels like it belongs to the people using it.

Thoughtful interfaces. Reliable systems.
Room to experiment.
