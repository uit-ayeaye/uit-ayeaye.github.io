PROJECT 08 / Commerce

Web + mobile + bots

DK Gaming Shop

Game top-ups and digital goods, connected to providers and order operations.

Domain LAB LTD · Myanmar

THE STORY

The context.

DK Gaming serves players buying MLBB, PUBG, in-game currency, and digital items. The interesting engineering happens between the storefront and fulfillment: product catalogs, wholesale providers, payment requests, approvals, and the team monitoring them.

MY CONTRIBUTION

My role.

Full shop-system implementation spanning storefront, admin management, wholesaler integration, mobile apps, and Telegram operations.

INSIDE THE BUILD

The details that make it work.

  • Next.js storefront for game catalogs, account checks, orders, and top-up history.
  • Wholesaler API integrations connect the retail catalog to fulfillment providers.
  • Telegram monitoring and approval flows support requests and order operations.
  • Android and iOS native project surfaces complement the web shop.
