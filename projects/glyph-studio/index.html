PROJECT 07 / Tools

Open-source project

Myanmar Glyph Studio

Draw a letter. Build a font. A creative tool for making Myanmar type feel like your own.

Open source · Myanmar typography

THE STORY

The context.

Myanmar typography has a beautiful complexity: stacked consonants, kinzi, vowel marks, and combinations that need to work together. Glyph Studio makes the starting point approachable with guided drawing in the browser, then connects those drawings to a real font-building pipeline.

MY CONTRIBUTION

My role.

Open-source font-creation toolkit, browser drawing experience, and the pipeline connecting portable glyph projects to installable fonts.

INSIDE THE BUILD

The details that make it work.

  • Phone-friendly guided tracing, stylus pressure, zoom, editable paths, and anchor positioning.
  • Export a draft TTF in the browser, or use the Python/UFO/fontmake pipeline for shaping-capable builds.
  • OpenType mym2 shaping, mark placement, and experimental variable-weight font generation.
  • A public specimen and font gallery show experimental faces generated with the platform.

TECHNOLOGIES

  • JavaScript
  • Python
  • OpenType
  • fontmake
  • PWA
