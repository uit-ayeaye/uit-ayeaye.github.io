# Midnight studio — September 20, 2026

The existing portfolio had a recognizable pirate/logbook identity, but rectangular primary actions, repeated gold outlines, abrupt disclosures, and large arch-shaped technology tiles made the interface feel less cohesive. The update preserves the artwork, project content, credits, and document routes while giving interactive elements a shared visual and motion language.

## Controls and layouts

| Area | Treatment |
| --- | --- |
| Primary actions | Soft coral/brass gradients, rounded corners, dark contact shadows, press depth, a short spring release, and a local light bloom. |
| Secondary actions | Dimmed surfaces and quieter borders; world launch and project-detail actions share a mobile row, stacking on the narrowest phones. |
| Header and mobile menu | Comfortable hit areas, hover underlines, animated menu entrance, existing Escape/outside dismissal. |
| Category filters and search | Compact pills, explicit selected fill, rounded input, and a visible focus halo. |
| Project, personal-site, and gallery cards | Consistent curved frames, layered shadows, a small pointer lift, and animated directional arrows. |
| World selector | Clear selected thumbnail, softer circular navigation, and a short stagger from title to next action. |
| Skills | Six original SVG mascots, category accent colors, miniature tool previews, compact rectangular icon tiles, and real symbols replacing monograms. |
| Disclosures | Native details enhanced with reversible height motion and staggered tool entrances. Closing content becomes inert until the animation finishes. |
| Project and résumé dialogs | Rounded dark frames, dimmed/blurred backdrops, generous close controls, and retained paper interiors. |
| Case studies | The same action treatment and softened preview frames. |
| Standalone worlds and articles | Animated shared voyage dock and press feedback. Scene control positioning and original engines stay independently owned. |
| Page navigation | Progressive cross-document view transitions in supporting browsers, without delaying links. |

The animation registry cancels active effects when motion is paused. OS reduced motion and the saved site preference remain authoritative. Touch actions do not require hover. Native links and disclosures remain available without JavaScript. No animation library, tracking, sound, or new external runtime was added.

- Static verifier passed 37 generated pages, including local assets, routes, anchors, credits, and private-project publication boundaries.
- JavaScript syntax and whitespace checks passed.
- CUA browser checks covered all 33 project modal records and all 33 mobile case-study routes.
- 28 viewport/theme/layout combinations passed without page or header overflow: 320, 390, 650, 768, 1024, 1440, and 2560 pixels; dark/light; grid/list.
- All six skill groups opened, keyboard activation closed disclosures, and a rapid double click settled without leaving a stuck height.
- Category counts, multi-word search, empty-state reset, and technology-to-project search worked.
- Personal-site controls advanced the rail; the initial previous control was disabled.
- Mobile menu Escape handling, world-tab Home navigation, world arrows, image inspection, résumé loading, and project modal focus return worked.
- OS reduced-motion emulation disabled decorative motion; the site's motion-off preference persisted after reload.
- No-JavaScript inspection retained all 33 project cards, navigation, and no horizontal overflow. CUA's click helper requires script execution, so no-JS disclosure clicking was not claimed.
- Six standalone world routes loaded their canvases and usable four-link voyage docks, with no mobile overflow. Both articles, gallery, and résumé loaded correctly.
- Desktop toolkit, mobile toolkit, mobile world launch actions, and mobile résumé were visually inspected. No browser console errors were reported during the final portfolio review.

These are browser and route checks, not physical-device tests or full gameplay/external-service audits. Cross-document transition appearance depends on browser support; ordinary links remain the fallback.
